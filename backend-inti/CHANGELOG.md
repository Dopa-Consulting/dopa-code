# Changelog

## 2024-06-25

### Cambios recientes

1. **Corrección de sesión incorrecta en Chat**: Se solucionó el problema donde al cambiar de sesión, persistían los mensajes de la sesión anterior.
2. **Mejora en la transcripción de audio**: Se agregó validación de API key para el servicio de STT y se mejoró el manejo de errores.
3. **Sincronización de workspace en pestaña Cambios**: Se corrigió la visualización del estado del workspace al cambiar entre pestañas.

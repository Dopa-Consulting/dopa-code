# tdd
**Categoria**: methodology
**Tags**: methodology, testing, quality

## Steps
1. Escribir test que falle (RED)
2. Escribir codigo minimo para pasar el test (GREEN)
3. Refactorizar manteniendo tests verdes (REFACTOR)
4. Repetir para cada feature

## Best Practices
- Tests unitarios primero, integracion despues
- Un test por comportamiento, no por metodo
- Mocks solo para I/O externo (DB, API, archivos)

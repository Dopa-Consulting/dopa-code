# brainstorming
**Categoria**: methodology
**Tags**: methodology, planning, design

## Steps
1. Entender el problema real que se quiere resolver
2. Explorar alternativas y trade-offs
3. Presentar diseño en secciones cortas para validacion
4. Guardar documento de diseño acordado

## Best Practices
- No saltar directo a codigo sin diseño aprobado
- Validar supuestos con datos reales
- Documentar decisiones de diseño y por que se tomaron

# writing-skills
**Categoria**: meta
**Tags**: meta, skills, documentation, methodology

## Steps
1. Identificar el proposito de la skill (que problema resuelve)
2. Escribir steps claros y accionables (imperativo, no descriptivo)
3. Agregar best practices con ejemplos concretos
4. Categorizar con tags relevantes
5. Testear la skill con un job de prueba
6. Iterar basado en feedback de agentes

## Best Practices
- Cada skill debe ser autocontenida
- Steps deben ser acciones concretas, no conceptos
- Usar tags consistentes con el ecosistema
- Mantener skills actualizadas con lecciones aprendidas

# writing_skills

Crear nuevas skills siguiendo el formato de Dopa Code.

**Origen**: obra/superpowers
**Tags**: meta, skills, universal

## Steps

1. Identificar el proposito de la skill (que problema resuelve)
2. Definir pasos concretos y verificables
3. Agregar mejores practicas basadas en experiencia
4. Categorizar con tags adecuados (dopaweb, general, design, etc.)
5. Testear la skill con un job de prueba

## Best Practices

- Pasos atomicos y ejecutables (2-5 min cada uno)
- Best practices basadas en experiencia real, no teoria
- Tags semantico: project_type + domain + safety_level
- Cada skill debe ser autocontenida

## Formato

```markdown
# nombre_skill

Descripcion corta.

**Origen**: repo/fuente
**Tags**: tag1, tag2, tag3

## Steps

1. Paso concreto
2. Paso verificable

## Best Practices

- Practica basada en experiencia
- Practica concreta y accionable
```

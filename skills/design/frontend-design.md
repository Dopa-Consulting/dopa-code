# frontend_design_principles

Principios de diseño para interfaces web: jerarquia visual, espaciado, tipografia, color.

**Origen**: anthropics/skills (frontend-design) + emilkowalski/skills
**Tags**: dopaweb, design, ui, frontend

## Steps

1. Analizar la jerarquia visual actual de la pagina
2. Verificar consistencia de espaciado (grid de 4px/8px)
3. Revisar tipografia: max 2 familias, scale consistente
4. Paleta de colores: primario, secundario, accent, neutral, semanticos
5. Asegurar contraste WCAG AA minimo
6. Responsive: mobile-first, breakpoints consistentes

## Best Practices

- Menos es mas: eliminar antes de agregar
- Espaciado generoso > comprimido
- Sombras semi-transparentes en vez de bordes solidos
- Animaciones sutiles: ease-out para entrada, ease-in para salida
- No usar mas de 2 typefaces
